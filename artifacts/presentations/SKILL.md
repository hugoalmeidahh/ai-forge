# Presentations artifacts

Read the audience, decision, source material, slide count constraints and template. Inspect master/layout relationships and existing content before editing. Lead with the point; each slide supports a specific part of the narrative.

Use an available presentation connector/library. Reuse supplied brand and layout, keep charts sourced and units explicit, and preserve notes and unmodified slides unless the change requires otherwise. Avoid fabricated logos, testimonials or statistics.

Save and reopen the resulting file. Render each created/affected slide when a compatible renderer is available; inspect overflow, clipped text, alignment, contrast and legibility at presentation size. Confirm the requested content and notes are present. If only HTML slides or source can be produced, make the format explicit rather than naming it a PowerPoint file.

## Output contract

Deliver the actual file in the requested format with a path/link, changed content and checks performed. Keep input documents and private metadata out of public commits. Discover required libraries/renderers before promising a result; install only within the task authorization. If the environment lacks a required capability, report the limitation and provide useful source/intermediate output without claiming the final artifact was verified.
